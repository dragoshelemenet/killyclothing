# KILLY6 static website

Static HTML/CSS/JS. Works on GitHub Pages.

## Run in Codespaces

```bash
npm install
npm run dev
```

## Add images

Each product has its own folder inside `assets/products/<product-slug>/`. Add photos there and list them in `data.js` under that product's `images` array.
